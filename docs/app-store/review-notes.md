# App Store Review Notes

**AgentHub — AI Agent Marketplace**

---

## App Purpose

AgentHub is an AI agent marketplace where users install pre-built AI agents for everyday tasks (writing emails, explaining bills, meal planning, etc.) and optionally set up time-based automations that deliver AI-generated results via push notification.

The app does **not** provide a raw chat interface. Each agent has a structured form with specific input fields, and the AI generates a focused output based on a curated system prompt.

---

## Account & Authentication

- **Sign in with Apple** (primary) and email/password authentication via Supabase Auth
- New users get a **7-day free trial** of the Pro tier
- No account required to browse the agent store; account required to install and run agents

---

## Subscription Model

AgentHub uses **auto-renewable subscriptions** managed via StoreKit 2:

| Product ID | Tier | Price | Key Features |
|---|---|---|---|
| `com.agenthub.starter.monthly` | Starter | $9.99/mo | 15 agents, 75 fast AI calls/day |
| `com.agenthub.pro.monthly` | Pro | $29.99/mo | 50 agents, smart+deep AI, 3 automations |
| `com.agenthub.unlimited.monthly` | Unlimited | $99.99/mo | Unlimited agents, all AI tiers, 10 automations |

- Free tier available with 3 agents and 10 fast AI calls/day
- Subscriptions unlock higher usage limits and automation features
- BYOK (Bring Your Own Key) is available on all tiers, including Free

## Test Instructions

### Testing Free Tier
1. Create account via Sign in with Apple or email
2. Browse the Agent Store — tap "Get" on any agent to install
3. Open an installed agent, fill the form, tap "Run"
4. Observe the AI response (uses platform-provided AI)
5. After 10 runs, you'll see a usage limit message

### Testing Subscriptions
1. Use a **Sandbox Apple ID** for StoreKit testing
2. Go to Settings → Subscription → select a tier
3. Complete the sandbox purchase flow
4. Verify the tier badge updates and usage limits increase
5. Test cancellation via Settings → Manage Subscription

### Testing Automations (Pro/Unlimited)
1. Subscribe to Pro or Unlimited tier
2. Navigate to the Automations tab
3. Tap "+" to create a new automation
4. Select an automation-capable agent (e.g., "Daily Plan Builder")
5. Set a schedule and save
6. The automation will run at the scheduled time and deliver a push notification

### Testing BYOK
1. Go to Settings → API Keys
2. Add an OpenAI or Anthropic API key
3. Run any agent — the response will be generated using your key
4. BYOK calls bypass daily usage limits

## Content & AI Usage

- AI responses are generated by **OpenAI** (GPT-4o, GPT-4o-mini) and **Anthropic** (Claude Haiku, Sonnet, Opus)
- All agent templates are curated and pass a security scanner that checks for prompt injection, data exfiltration, and content policy violations
- The app does **not** allow users to write arbitrary prompts — all agents use structured forms with validated inputs
- AI outputs include a disclaimer that they are AI-generated and should not be relied upon for professional advice

---

## Push Notifications

- Used exclusively for delivering automation results (e.g., "Your Daily Plan is ready")
- Users must explicitly create an automation and grant notification permission
- No marketing or promotional push notifications

---

## Privacy

- See in-app Privacy Policy (also at `docs/legal/privacy-policy.md`)
- No tracking, no ads, no data selling
- BYOK keys encrypted with AES-256-GCM
- All data protected by Row Level Security — users can only access their own data

---

## Technical Notes

- **Minimum iOS version**: 17.0
- **Backend**: Supabase (Edge Functions + PostgreSQL + Auth)
- **AI providers**: OpenAI API, Anthropic API
- **Push**: APNs via HTTP/2
- **No web views** — fully native SwiftUI
